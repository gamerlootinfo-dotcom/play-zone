# Play-Zone (Dostlarla Əyləncə Platforması) 🎮

Partiya və stolüstü oyunlar platforması: **İmposter (Casus)** və **Klassik Mafia**.

## Xüsusiyyətlər
- 🕵️‍♂️ **İmposter (Casus):** 1000-dən çox söz cütlüyü, dinamik qarışdırma və random ilk başlayan ruletkası.
- 👑 **Klassik Mafia:** Don, Sıravi Mafiya, Komissar, Həkim, Dinc Sakinlər rolları, gecə/gündüz interaktiv aparıcı bələdçisi.
- 📱 **Mobil & Planşet Uyğunluğu:** Telefonu əldən-ələ ötürərək toxunub-saxlama (Hold-to-reveal) kart animasiyası.
- 🔊 **Səs effektləri və Haptik vibrasiya dəstəyi.**
- ⚡ **Next.js 15, React 19 və Tailwind CSS ilə hazırlanıb.**

## İşə salmaq
```bash
npm install
npm run dev
```
